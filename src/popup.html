Track your GitLab merge requests

GitLab MR Watcher shows open merge requests created by you and merge requests waiting for your review, grouped by project.

  1. Open settings.
  2. Enter your GitLab URL.
  3. Create a GitLab access token and select all scopes for the simplest setup.
  4. Choose an auto-refresh interval.

This extension is local-first: your token and MR cache stay in this browser, and requests go only to the GitLab URL you configure.
